LeetCode 竞赛级通关路线图 (Phase 0 -> Phase 4)

Nov 26, 2026 · Leetcode · 3 min read
  • Phase 0：刷题地基（进行中）
  • Phase 1：线性结构与单调性（面试 ~40% 高频 + 竞赛 Q1/Q2 稳拿）
  • Phase 2：递归、树、搜索与图论基础（思维跃迁期）
  • Phase 3：最优化分水岭（Medium / Hard 核心 + 竞赛 Q3 稳拿）
  • Phase 4：竞赛 AK 兵器库（冲刺 Q4 / Guardian 2200+）

核心原则：不按题号盲刷；严格按前置依赖逐块打通底层模型与不变量。
每次循环：1 个最小知识块讲解 → 你用自己的逻辑写 Obsidian 笔记并费曼审校 → 1~3 道分级题（4 级防剧透提示）→ 记录掌握度与间隔复习 → 循环。
进度追踪目录：每个阶段的动态掌握度、断点与到期复习队列保存在 learning-state/<topic-slug>.md。

Phase 0：刷题地基（进行中）

状态文件：learning-state/phase0-foundations.md

  • 0.1 时间复杂度与数据范围反推法（Big-O、Python $10^7$ 红线、由 $n$ 反推目标复杂度）
  • 0.2 空间复杂度与时空权衡（额外空间、递归调用栈空间）
  • 0.3 Python 刷题容器的真实代价（list / deque / dict / set / heapq / bisect）
  • 0.4 循环不变量（Loop Invariant）初体验（消灭 off-by-one 边界玄学的底层武器）

Phase 1：线性结构与单调性（面试 ~40% 高频 + 竞赛 Q1/Q2 稳拿）

  • 1.1 哈希表与两数/映射思维（dict / Counter 空间换时间）
  • 1.2 前缀和与差分数组（一维 → 二维 → 前缀和 + 哈希表）
  • 1.3 双指针（相向双指针、同向双指针、快慢指针）
  • 1.4 滑动窗口（定长 → 不定长；何时成立、为何负数破坏单调性）
  • 1.5 二分查找与二分答案（红蓝染色循环不变量 → 最小化最大值 / 最大化最小值）
  • 1.6 链表与指针重构（哨兵节点、反转、环检测与入口推导）
  • 1.7 栈、队列、单调栈与单调队列（下一个更大元素、贡献法、滑动窗口最值）

Phase 2：递归、树、搜索与图论基础（思维跃迁期）

  • 2.1 递归本质与二叉树（自顶向下“递” vs 自底向上“归”）
  • 2.2 BST、堆（优先队列）与 Trie（前缀树）（Top-K、对顶堆、懒删除堆）
  • 2.3 回溯与剪枝（子集 / 组合 / 排列的决策树模型与去重不变量）
  • 2.4 图论基础（建图、DFS/BFS 连通块、多源 BFS、0-1 BFS）
  • 2.5 拓扑排序与并查集（Union-Find）（DAG 依赖、带权并查集、按秩合并）

Phase 3：最优化分水岭（Medium / Hard 核心 + 竞赛 Q3 稳拿）

  • 3.1 贪心与证明方法（邻项交换论证、区间调度、反悔贪心）
  • 3.2 动态规划统一框架（从回溯 → 记忆化搜索 @cache → 递推 → 空间压缩）
  • 3.3 经典 DP 模型（线性 DP、网格 DP、0-1/完全/多重背包、状态机 DP）
  • 3.4 进阶 DP 基础（LIS/LCS 子序列 DP、区间 DP、树形 DP、换根 DP）
  • 3.5 最短路与最小生成树（Dijkstra、Bellman-Ford/SPFA、Floyd、Kruskal）

Phase 4：竞赛 AK 兵器库（冲刺 Q4 / Guardian 2200+）

  • 4.1 位运算技巧与状压 DP（Bitmask DP）（子集枚举、SOS DP）
  • 4.2 数位 DP 与单调队列/斜率优化 DP（数位记忆化模板、DP 转移降维）
  • 4.3 高级数据结构（树状数组 BIT、线段树与懒标记、离线查询）
  • 4.4 字符串算法（KMP、Z 函数、滚动哈希、Manacher）
  • 4.5 数论、组合数学与博弈论（质数筛、逆元与组合数、容斥、SG 函数）
