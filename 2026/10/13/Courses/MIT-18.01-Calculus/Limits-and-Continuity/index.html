Definitions of right-hand and left-hand limits

定义左右的极限

Apporch的概念就是：无限接近一个固定的数 但是永远不会达到这个数

假设我们要approch A
左右极限就是从左边 ($-\infty$,a) 接近 右边就是从(a,$\infty$)

写法就是:

$f(x) \rightarrow R \text{ as } x \rightarrow a^{+}$
或者是

$\lim_{x\rightarrow a^{+}} f(x) = R$

左边就是 $a^{-}$

limits 可能出现的情况:

  • 两者共同存在并且相同
  • 左右互相存在但不相同 (Jump discontinuity)
  • 左右可能不存在 因为正无限或负无限(limits dont exist infty is not real number)
  • 左右极限可能不存在 因为无法apporch一个固定的value (Oscillating Discontinuity)

Definition of the Limit (极限的定义)

如果左右limits都存在并且 同样等于
我们说这个overall limits exists(一般的limits 指的就是overall limtis)

$\lim_{x\rightarrow a} f(x) = L$
or
$f(x) \rightarrow L \text{ as } x \rightarrow a$

The limits laws:

Suppose $\lim_{x \to a} f(x) = L, \quad \lim_{x \to a} g(x) = M.$

Then we get the following Limit Laws:

  • Limit Law for Addition:

    $$\lim_{x \to a} [f(x) + g(x)] = L + M$$

  • Limit Law for Subtraction:

    $$\lim_{x \to a} [f(x) - g(x)] = L - M$$

  • Limit Law for Multiplication:

    $$\lim_{x \to a} [f(x) \cdot g(x)] = L \cdot M.$$

  • Limit Law for Division, Part 1:

    $$\text{If } M \neq 0, \text{ then } \lim_{x \to a} \frac{f(x)}{g(x)} = \frac{L}{M}.$$

也就是我们正常常数的 + - × ÷

Continuty

连续也就是

$\lim_{x\rightarrow a} f(x) = f(a)$

这里说的是overall continuous 跟limits一样可以分左右

  • right-continuous
  • left-continuous

如果f(x) 和 limits not exist 我们就说discontinuty

Types of Discontinuities (at $x = a$)

  1. Removable Discontinuity (可去间断点)
    • Condition: Overall limit exists and is finite ($\lim_{x \to a^-} f(x) = \lim_{x \to a^+} f(x) = L \in \mathbb{R}$).
    • Formula:
      $$\lim_{x \to a} f(x) \neq f(a) \quad (\text{or } f(a) \text{ is undefined})$$
  1. Jump Discontinuity (跳跃间断点)
    • Condition: Both one-sided limits exist and are finite ($\lim_{x \to a^-} f(x), \lim_{x \to a^+} f(x) \in \mathbb{R}$).
    • Formula:
      $$\lim_{x \to a^-} f(x) \neq \lim_{x \to a^+} f(x)$$
  1. Infinite Discontinuity (无穷间断点)
    • Condition: At least one one-sided limit diverges to infinity.
    • Formula:
      $$\lim_{x \to a^-} f(x) = \pm\infty \quad \text{or} \quad \lim_{x \to a^+} f(x) = \pm\infty$$
  1. Essential / Oscillating Discontinuity (本性/振荡间断点)
    • Condition: At least one one-sided limit does not exist (and is not $\pm\infty$).
    • Formula:
      $$\lim_{x \to a^-} f(x) \text{ DNE} \quad \text{or} \quad \lim_{x \to a^+} f(x) \text{ DNE}$$

Basic continiuous functions

  • all polynomials

  • abs(x)

  • cos(x) and sin(x)

  • exponential functions

有一些则是在特定区域

  • tan(x)

  • $\log_a(x) \text{ where } a > 0, x > 0$

  • $\sqrt{x} \text{ where } x \ge 0$

Limit laws 与 continuity

假设 $f$ and $g$ are continuous everywhere, then:

  • $f + g$ is continuous everywhere.
  • $f - g$ is continuous everywhere.
  • $f \cdot g$ is continuous everywhere.
  • $\dfrac{f}{g}$ is continuous where it is defined.

Intermediate Value Theorem

Theorem 1 (Intermediate Value Theorem (介值定理))

If $f$ is continuous on the closed interval $[a, b]$, and $M$ lies between $f(a)$ and $f(b)$, then there exists at least one $c \in (a, b)$ such that $f(c) = M$.

直觉就是一个连续的函数 假设有两点 a b 必须有一个点至少穿过它们中间的一个value (线不会断开)

(A function $f$ is continuous on a closed interval $[a, b]$ if it is right-continuous at $a$, left-continuous at $b$, and continuous at all points between $a$ and $b$.)

Limit Law for Division (处理除法为0的)

If $\lim_{x \to a} f(x) = L$ and $\lim_{x \to a} g(x) = M$, then:

  • If $M \neq 0$, then $\lim_{x \to a} \dfrac{f(x)}{g(x)} = \dfrac{L}{M}$.
  • If $M = 0$ but $L \neq 0$, then $\lim_{x \to a} \dfrac{f(x)}{g(x)}$ does not exist.

如果上下都为0 则需看看能不能约和做l hopital rule 等等

The Definition of the average rate of change

其实这里也就是slope 斜率的公式

The average rate of change of a function $f(x)$ over an interval $a \leq x \leq b$ is defined to be

$$\frac{f(b) - f(a)}{b - a}.$$

Definition of the derivative

导数也就是一个固定的点 和另外一个apporching的点的斜率来近似一个点斜率

The derivative of a function $f(x)$ at a point $x = a$ is defined to be

$$f'(a) = \lim_{b \to a} \frac{f(b) - f(a)}{b - a}.$$

Secant lines 穿过两点

  • average rate of change 也是 slope
  • $\text{slope} = \frac{f(b)-f(a)}{b-a}$
  • $$y = \frac{f(b)-f(a)}{b-a}(x-a) + f(a)$$

Tangent lines 穿过一点 并且 slope 是 instantaneous rate of change

  • $$y = f'(a)(x-a) + f(a)$$

一些与平时代数相似性 函数 + - 和常数 乘除

  • $g(x) = k f(x)$ then $g'(x) = k f'(x)$ where $k$ is a constant
  • $h(x) = f(x) + g(x)$ then $h'(x) = f'(x) + g'(x)$ same for minus

上面这种性质叫线性 Linearity (

  1. 加法能拆开；
  2. 乘以固定数字能提出来 )
  • $$f(x) = x^n , \quad f'(x) = nx^{n-1}$$

Leibniz notation

也就是 $\frac{dy}{dx}$ 这种

还有另外一种是 Newtons notation $f'(x)$ 那种

  • Units: If $P$ has units of pressure, and $t$ has units of $time$, then $\frac{dP}{dt}$ has units of pressure per time.
  • Evaluating at points: If we want to take the derivative at a particular point $x = 3$, then we use the notation $\left.\frac{df}{dx}\right\vert{}_{x=3}$. The bar is read as “evaluated at".
  • Derivatives act on functions:
    • We can write $\frac{d(x^2)}{dx}$ for the derivative of $x^2$.
    • If a formula is long, we can write $\frac{d}{dy}(y^3 + 2y^2)$.

高阶导数

对于 $n$ 次的导数 就是 $\frac{d^n f}{dx^n}$

二次导数的特性

  • $f''$ 如果是正 就是 concave up （记的方法就是最终的value会go up)
  • $f''$ 如果是副 就是 concave down (记的方法跟上面同理 最终value会go down)

infection points $f'' = 0$ 也就是从 concave up 转去 concave down 的点

三角导数

  • $d(\sin) = \cos$
  • $d(\cos) = -\sin$
  • $d^2(\sin) = -\sin$
  • $d^2(\cos) = -\cos$

线性近似 Linear approximation

也就是弄一个新的线性函数来近似 那个点附近的值

当 $x$ 接近 $a$（即 $\Delta x$ 接近 $0$）时：

  • $\Delta f \approx \left. \frac{df}{dx} \right|_{x=a} \cdot \Delta x$
  • $f(x) \approx f'(a)(x - a) + f(a)$

Product Rule (乘积法则)

若 $h(x) = f(x)g(x)$，当 $f'(x)$ 和 $g'(x)$ 存在时：

  • $h'(x) = f(x)g'(x) + g(x)f'(x)$
  • 简记：$(fg)' = fg' + gf'$

Quotient Rule (商法则)

若 $h(x) = \frac{f(x)}{g(x)}$，当 $f, g$ 可导且 $g(x) \neq 0$ 时：

  • $h'(x) = \frac{f'(x)g(x) - f(x)g'(x)}{g(x)^2}$
  • 简记：$\left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2}$

下d上- 上d下

三角函数导数 (Trigonometric Derivatives)

  • $\frac{d}{dx} \sin x = \cos x$
  • $\frac{d}{dx} \cos x = -\sin x$
  • $\frac{d}{dx} \tan x = \frac{1}{\cos^2 x} = \sec^2 x$
  • $\frac{d}{dx} \cot x = -\frac{1}{\sin^2 x} = -\csc^2 x$
  • $\frac{d}{dx} \sec x = \frac{\sin x}{\cos^2 x} = \sec x \tan x$
  • $\frac{d}{dx} \csc x = -\frac{\cos x}{\sin^2 x} = -\csc x \cot x$

chain rule

永远只记

$$\frac{dy}{\cancel{du}}\times \frac{\cancel{du}}{dx}$$

隐微分 (Implicit Differentiation)

隐微分 也就是 有formula 不是函数 但是也可以求导数

总之就是把 $\frac{d}{dx}$ 当成一个操作符号，需要对左右 和 每个item 都做就行。

定义 (Implicit Functions)

  • 隐函数 (Implicit function)：一个同时包含 $x$ 和 $y$ 的方程（解出 $y$ 关于 $x$ 的表达式通常很繁琐或不可能）。非隐式的函数称为显式函数 (Explicit)。
  • 核心作用：当方程用隐式表达更简单时（例如把 $y = x^{m/n}$ 写成 $y^n = x^m$），直接两边同时隐微分会简单得多。

inverse function 反函数

$f(x) = y$

$f^{-1}(y) = x$

Definition of one to one

A function $f$ is one-to-one if $f(a) \neq f(b)$ whenever $a \neq b$. It is one-to-one if and only if its graph satisfies the horizontal line test (no horizontal line intersects its graph at more than one place).

Domain and range, interval notation

  • domain 输入
  • range 输出

interval () 是不包含 [] 是包含（如闭区间 $[a, b]$ 表示 $a \le x \le b$，开区间 $(a, b)$ 表示 $a < x < b$，具体可结合 ±$\infty$ 延伸理解）。

Derivatives of inverse functions

对于反函数关系：

$$f^{-1}(y) = x \quad \text{或记作 } g(x) = f^{-1}(x)$$

我们可以透过对 $f(f^{-1}(x)) = x$ 两边关于 $x$ 做求导，利用 chain rule（$\frac{d}{dx}$ 作用于复合函数，配合 $\frac{dy}{dx}$）：

  1. 已知 $f(g(x)) = x$
  2. 两边对 $x$ 求导：
$$\frac{d}{dx} [f(g(x))] = \frac{d}{dx} [x]$$
  1. 运用链式法则（$\frac{d}{dy}f(y) \cdot \frac{dy}{dx}$）：
$$f'(g(x)) \cdot g'(x) = 1$$
  1. 移项即得反函数的导数公式：
$$g'(x) = \frac{1}{f'(g(x))}$$

指数函数的导数

指数函数的导数为：

$$\frac{d}{dx} a^x = M(a) a^x, \quad (4.42)$$

其中，神秘数 $M(a)$ 是函数在 $x = 0$ 处的切线斜率：

$$M(a) = \left. \frac{d}{dx} a^x \right\vert{}_{x=0} = \lim_{\Delta x \to 0} \frac{a^{\Delta x} - 1}{\Delta x}.$$

M(a)就是ln(a)

$e$ 的定义

底数 $e$ 是使得 $M(e) = \left. \frac{d}{dx} e^x \right\vert{}_{x=0} = 1$ 成立的唯一实数。因此：

$$\frac{d}{dx} e^x = e^x. \quad (4.43)$$
