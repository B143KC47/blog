Handling Missing Values（处理缺失值）

读入数据 → 看前几行 → 统计缺失值 → 判断缺失原因 → 删除 或 填充

missing_values_count = nfl_data.isnull().sum()   # 每一列的缺失个数
total_cells = np.product(nfl_data.shape)          # 总格子数 = 行数 × 列数
total_missing = missing_values_count.sum()
percent_missing = total_missing / total_cells * 100
